les départs d'employés à partir de données RH réelles.

## 🔍 Analyses réalisées
- **Attrition par BusinessTravel** — les voyages fréquents concentrent 52% des départs
- **Attrition par Seniority & Gender** — les nouveaux employés ont un taux 3x supérieur
- **Attrition par Rôle** — Sales Representatives largement en tête
- **Analyse croisée Âge × Département** — les 18-25 ans en Sales à 43,90%
- **Satisfaction par Seniority** — chute marquée chez les Junior
- **Attrition par MaritalStatus** — les célibataires partent plus
